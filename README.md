# 🌱 Smart Vertical Garden

An AI-powered eco-friendly vertical gardening system built using FastAPI, Python, HTML, CSS, and JavaScript.

## 🚀 Live Website

https://omkumar-rajput.github.io/EVS/

## 🔥 Features

- 🌿 Smart plant monitoring
- 💧 Watering reminders
- 📈 Plant growth tracking
- 🤖 AI Plant Care Advisor
- ♻️ Eco-friendly vertical bottle garden concept
- 🧠 FastAPI backend integration
- ☁️ Public cloud deployment using Render

## 🛠 Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- SQLite

### AI Integration
- OpenRouter API
